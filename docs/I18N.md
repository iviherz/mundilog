# Interfaz en seis idiomas

Español (`es`), inglés (`en`), francés (`fr`), ruso (`ru`), chino simplificado (`zh`) y árabe (`ar`). Son los seis idiomas oficiales de Naciones Unidas: https://www.un.org/en/our-work/official-languages. No existe aquí una lista adicional de «todos los idiomas reconocidos por la ONU».

El selector aparece en todas las páginas. La cookie `locale` recuerda la preferencia durante un año en ese navegador. En la primera visita se negocia `Accept-Language`; español es el fallback. No se solicita ninguna API de traducción, no se comparten textos con terceros y no hacen falta claves nuevas ni migraciones de Supabase. Cambiar el idioma recarga la página: guardar primero cualquier formulario incompleto. La vista de prueba pierde sus cambios al recargarse.

La interfaz, textos informativos, categorías, tags, países, mapa, mensajes conocidos de error y manifest se traducen. Los nombres de países se obtienen con `Intl.DisplayNames` y códigos ISO de dos letras. El catálogo de la base de datos conserva sus códigos y nombres originales. Los mensajes y consejos escritos por personas, nombres de lugares, bios y colecciones conservan su idioma original. Un nombre personalizado mediante `APP_NAME` se conserva.

Árabe usa `dir=rtl`; la geografía del mapa no se refleja. Chino usa escritura simplificada. La página offline ofrece enlaces para elegir cualquiera de los seis idiomas y solo almacena contenido público estático. La frase de confirmación de borrado sigue siendo `BORRAR MI CUENTA` en todos los idiomas y se explica en la etiqueta traducida.

Los catálogos `lib/i18n/*.json` son archivos públicos de texto de interfaz: no deben contener credenciales ni información de usuarios. Cada traducción nueva debe incluirse en los seis catálogos. Son traducciones iniciales; revisar el estilo con hablantes nativos antes de lanzar públicamente, especialmente textos legales.

## Validación

`npm run typecheck` genera primero los tipos de Next para funcionar también en un checkout limpio. `npm test` verifica igualdad de catálogos, negociación de idioma, países, datos, privacidad y fotos. `npm run build` crea el bundle de producción. `npm run test:e2e` comprueba cada idioma, persistencia, protección del endpoint, escritorio y móvil; ejecuta axe en español y árabe.

`next-env.d.ts` sí se versiona. Lo genera Next.js y no contiene claves. No versionar `.next`, `node_modules`, `.env` ni `.env.local`. `.env.example` contiene solo nombres y ejemplos sin secretos.
